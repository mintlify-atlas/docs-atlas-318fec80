Once you've installed the dependencies, you can start developing the application locally.

## Starting the development server

<Steps>
  <Step title="Start the dev server">
    Run the development server with hot module replacement:

    <CodeGroup>
    ```bash npm
    npm run dev
    ```

    ```bash yarn
    yarn dev
    ```

    ```bash pnpm
    pnpm dev
    ```
    </CodeGroup>

    The server will start on **port 3000** by default.
  </Step>

  <Step title="Open in browser">
    Navigate to [http://localhost:3000](http://localhost:3000) to see the app running.

    The page will automatically reload when you make changes to the source code.
  </Step>
</Steps>

<Info>
  Vite provides extremely fast hot module replacement (HMR), so your changes appear almost instantly in the browser.
</Info>

## Available scripts

The project includes several npm scripts for development:

### `dev`
Starts the Vite development server with HMR on port 3000.

```bash
npm run dev
```

### `build`
Creates an optimized production build in the `dist/` directory.

```bash
npm run build
```

### `preview`
Serves the production build locally for testing before deployment.

```bash
npm run preview
```

### `lint`
Checks code for issues using Biome.

```bash
npm run lint
```

### `lint:fix`
Automatically fixes linting issues where possible.

```bash
npm run lint:fix
```

### `format`
Formats code according to project style rules.

```bash
npm run format
```

### `test`
Runs the test suite using Vitest.

```bash
npm run test
```

## Vite configuration

The app uses Vite with the following configuration:

```typescript
import react from '@vitejs/plugin-react'
import jotaiDebugLabel from 'jotai/babel/plugin-debug-label'
import jotaiReactRefresh from 'jotai/babel/plugin-react-refresh'
import { defineConfig } from 'vite'
import tsconfigPaths from 'vite-tsconfig-paths'

export default defineConfig({
  plugins: [
    react({ 
      babel: { 
        plugins: [jotaiDebugLabel, jotaiReactRefresh] 
      } 
    }), 
    tsconfigPaths()
  ],
  server: {
    port: 3000,
  },
})
```

**Key plugins:**
- **@vitejs/plugin-react** - Enables React Fast Refresh
- **jotai/babel/plugin-debug-label** - Adds debug labels to Jotai atoms
- **jotai/babel/plugin-react-refresh** - Preserves atom state during HMR
- **vite-tsconfig-paths** - Resolves TypeScript path aliases (`~/*`)

## State management

The app uses Jotai for state management with a provider at the root:

```tsx
import { Provider } from 'jotai'

root.render(
  <React.StrictMode>
    <Provider>
      <App />
    </Provider>
  </React.StrictMode>
)
```

All state is managed through atoms defined in `src/state/Atoms.tsx`. See the [state management](/state-management) guide for details.

## Styling approach

The app uses Tailwind CSS for styling:

- **Utility-first** - Classes like `bg-gradient-to-br`, `backdrop-blur-md`
- **Custom colors** - Defined in `tailwind.config.js` (e.g., `ocean-blue`, `lollipop`)
- **Responsive design** - Mobile-first with `sm:`, `md:` breakpoints
- **Glassmorphism** - Semi-transparent backgrounds with backdrop blur

## TypeScript

The project is written in TypeScript with strict mode enabled. Type checking happens during:

- Development (in your editor)
- Build time (via Vite)
- Testing (via Vitest)

All component props and data structures are fully typed.

## Troubleshooting

### Port already in use

If port 3000 is already taken, you can change it in `vite.config.ts`:

```typescript
server: {
  port: 3001, // or any available port
}
```

### HMR not working

If hot module replacement stops working:

1. Stop the dev server (Ctrl+C)
2. Clear the Vite cache: `rm -rf node_modules/.vite`
3. Restart: `npm run dev`

### Type errors

If you see TypeScript errors that don't make sense:

1. Restart your editor's TypeScript server
2. Delete `node_modules` and reinstall dependencies
3. Check `tsconfig.json` for any issues
