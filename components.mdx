The app is built with a simple, functional component architecture using React and Jotai for state management. All components are functional components using hooks.

## Component hierarchy

The component tree follows this structure:

```plaintext
App
├── Toolbar
├── DailyMessage
├── Illustration
└── ShipList
    └── ShipListItem
        └── Field
```

  <Tab title="Illustration">
    Renders decorative visuals that change based on the number of ships visiting.

    **Location:** `src/components/Illustration.tsx:7`

    **Props:** None

    **State:**
    - Reads from `selectedShipList` atom

    **Visual states:**
    - **0 ships:** Shows a buoy SVG illustration
    - **1 ship:** Shows a single centered boat icon (8rem, ocean-blue)
    - **2 ships:** Shows two boat icons (6rem lollipop, 8rem ocean-blue)
    - Always displays a wave pattern at the bottom

    ```tsx
    export const Illustration = () => {
      const [shipList] = useAtom(selectedShipList)
      return (
        <div className="mt-14 flex h-full min-h-[20rem]">
          <div className="w-full self-end">
            {/* Two Ships*/}
            {shipList.length === 2 && (
              <>
                <Boat size="6rem" className="ml-[20%] text-lollipop" />
                <Boat size="8rem" className="ml-[60%] text-ocean-blue" />
              </>
            )}
            {/* One Ship*/}
            {shipList.length === 1 && <Boat size="8rem" className="mx-auto text-ocean-blue" />}
            {/* No Ship(s)*/}
            {shipList.length === 0 && <img src={Buoy} alt="Buoy" className="mx-auto mt-32 w-2/12 sm:w-1/12" />}
            <div className="flex justify-center">
              {/* Wave icons */}
            </div>
    ```

  <Accordion title="ShipList">
    Container component that renders the list of ships for the selected date.

    **Location:** `src/components/shipList/ShipList.tsx:6`

    **Props:** None

    **State:**
    - Reads from `selectedShipList` atom (filtered by selected date)

    **Behavior:**
    - Maps over the ship array and renders a `ShipListItem` for each
    - Determines if a ship is anchored based on notes containing "ANKER"
    - Uses ship name and index as the key for list rendering

    ```tsx
    export const ShipList = () => {
      const [shipList] = useAtom(selectedShipList)

      return (
        <div className="relative mx-auto max-w-[768px]">
          {shipList.map((ship, index) => (
            <ShipListItem
              key={`${ship.shipName}-${index}`}
              ship={ship}
              anchoredShip={ship.notes.toUpperCase().includes('ANKER')}
            />
          ))}
        </div>
      )
    }
    ```

## Design patterns

### State consumption

All components consume state through Jotai's `useAtom` hook. No props are passed for data - components read directly from atoms:

```tsx
import { useAtom } from 'jotai'
import { selectedShipList } from '~/state/Atoms'

export const ShipList = () => {
  const [shipList] = useAtom(selectedShipList)
  // ...
}
```

### Suspense boundaries

Async data loading is handled at the root level with React Suspense, providing a clean loading state:

```tsx
<Suspense fallback={<div className="bg-base">Loading...</div>}>
  {/* App content */}
</Suspense>
```

### Responsive design

Components use Tailwind's responsive prefixes (`sm:`, `md:`) for mobile-first responsive layouts:

```tsx
<div className="my-4 flex flex-col md:flex-row">
  {/* Stacks vertically on mobile, horizontal on desktop */}
</div>
```

## Styling approach

The app uses Tailwind CSS with custom colors defined in the configuration:

- `ocean-blue` - Primary ship color
- `lollipop` - Anchored ship accent color  
- `midnight-blue` - Text color
- Gradient backgrounds using `from-sky-200 via-sky-300 to-cyan-200`
- Glassmorphism with `bg-white/10 backdrop-blur-md`
