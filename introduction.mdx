## Welcome aboard

Hvilken Båt Er Det I Dag ("Which boat is it today") is a React application that displays the daily cruise ship schedule for Eidfjord, Norway. Built with modern web technologies, it provides an elegant and interactive way to track visiting cruise ships throughout the summer season.

<Note>
  The app fetches real-time schedule data from a remote source and displays detailed information about each vessel, including tonnage, passenger capacity, ports of call, and anchor status.
</Note>

## Technology stack

The application is built with a modern React stack that prioritizes performance and developer experience:

- **React 19** - Latest React with concurrent features
- **Jotai** - Atomic state management for predictable data flow
- **TanStack Query** - Server state management via `jotai-tanstack-query`
- **Tailwind CSS** - Utility-first styling with custom theme
- **Day.js** - Lightweight date manipulation
- **Zod** - Runtime type validation for API data
- **Vite** - Fast build tooling and HMR

<Info>
  The app uses Jotai atoms to manage state, combining local date selection with remote schedule data through derived atoms.
</Info>

## What makes this app special

Hvilken Båt Er Det I Dag demonstrates several modern React patterns:

**Type-safe data fetching** - The app uses Zod schemas to validate API responses at runtime, ensuring type safety from the network boundary:

```typescript
const ship = z
  .object({
    day: z.string(),
    date: z.string(),
    anchorTime: z.string(),
    shipName: z.string(),
    tonnage: z.number(),
    length: z.number(),
    maxPassengers: z.number(),
    nationality: z.string(),
    // ... more fields
  })
  .strict()

export type Ship = z.infer<typeof ship>
```

**Atomic state composition** - State is split into focused atoms that derive from each other, creating a clear dependency graph:

```typescript
// Base atom for selected date
export const selectedDay = atom<Dayjs>(dayjs())

// Derived atom that filters ships by selected date
export const selectedShipList = atom((get) => {
  const scheduleResult = get(schedule)
  if (scheduleResult.data && Array.isArray(scheduleResult.data)) {
    return scheduleResult.data.filter(
      (ship: Ship) => ship.date === get(selectedDay).format('DD.MM.YYYY')
    )
  }
  return []
})
```

**Keyboard-driven UX** - Arrow key navigation is implemented at the component level with proper cleanup:

```typescript
const handleKeyDown = useCallback(
  (e: KeyboardEvent) => {
    switch (e.key) {
      case 'ArrowLeft':
        subtractDay()
        break
      case 'ArrowRight':
        addDay()
        break
    }
  },
  [addDay, subtractDay]
)

useEffect(() => {
  window.addEventListener('keydown', handleKeyDown)
  return () => {
    window.removeEventListener('keydown', handleKeyDown)
  }
}, [handleKeyDown])
```
